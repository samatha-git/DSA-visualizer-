# DSA Visualizer

An interactive browser-based learning tool for understanding sorting and searching algorithms step by step.

## Algorithms
- Bubble Sort
- Selection Sort
- Insertion Sort
- Linear Search
- Binary Search (runs on a sorted copy of the input)

## Features
- Step-by-step and automatic playback
- Adjustable animation speed
- Editable comma-separated input values
- Search target selection
- Comparison and write/swap counters
- Plain-language explanation for each operation
- Time and space complexity summary

## Run locally
Open `index.html` in a modern web browser. No installation or backend is required.

## Technologies
HTML, CSS, JavaScript.

## Resume description (use after testing and understanding the code)
**Interactive DSA Visualizer**
- Built a browser-based tool to visualize Bubble Sort, Selection Sort, Insertion Sort, Linear Search, and Binary Search.
- Added step controls, animation speed settings, operation counters, and explanations of algorithm behavior.
- Presented time and space complexity to support learning and comparison of fundamental algorithms.

## Limitations
This is an educational visualization tool, not a code execution judge. Operation counters are illustrative and depend on the visualization steps generated. Binary Search sorts a copy of the entered values before searching.
